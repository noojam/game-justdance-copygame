# game-justdance-copygame

## 고등학교 동아리에서 친구랑 개발한 저스트 댄스 카피게임

- Justdance2에 수록된 보니 엠의 '라스푸틴' 노래에 맞춰 화면에 보이는 아바타의 춤을 따라 추는 게임입니다.

- xbox one의 kinect v2를 사용하여 ipi motion capture를 통해 아바타의 애니메이션을 만들었습니다.

- kinect v2 센서를 통해 플레이어의 관절 위치를 3d로 추출하고 아바타의 관절이 이루는 벡터와 플레이어의 관절이 이루는 벡터의 내적을 통해 점수를 산출합니다.

- unity 2022.3.4f1으로 빌드되었습니다.
